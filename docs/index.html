インストール方法

  1. BVE Trainsim 5 をインストールしてください。
  2. 上のダウンロードボタンからZIPファイルをダウンロードします。
  3. ZIPを解凍し、Scenarios フォルダの中身（東京メトロ日比谷線-38S_北千住行.txt・東京メトロ日比谷線-46S_北千住行.txt と Tadimaru フォルダ）を BVE の Scenarios フォルダにコピーします。
  4. 下記「使用車両について」を参考に、シナリオファイル内の Vehicle = 行を書き換えます。
  5. BVE を起動し、シナリオ一覧から「東京メトロ日比谷線」を選択してください。

使用車両について

この路線はATC（自動列車制御装置）を実装しています。動作にはメトロ総合プラグイン対応の車両が必要です。

指定車両は設けていません。Scenarios/ 内の各シナリオファイル（〜-38S_北千住行.txt・〜-46S_北千住行.txt）にある Vehicle = ここにお好きな車両を指定してください の行を、お手持ちの車両ファイルのパスに書き換えてください。

運転方法（ATC起動手順）

始発駅出発前に、以下の手順で保安装置を起動してください。

  1. 非常ブレーキをかけ、シフトレバーを中立にします。
  2. 8キーを押して保安装置を「東京メトロ（営団）」に設定します。
    ※車両によって異なる場合があります
  3. ブレーキを緩めると ATC が作動します。

使用プラグイン
