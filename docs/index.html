インストール方法

  1. BVE Trainsim 5 をインストールしてください。
  2. 上のダウンロードボタンからZIPファイルをダウンロードします。
  3. ZIPを解凍し、Scenarios フォルダの中身（東京メトロ日比谷線.txt と Tadimaru フォルダ）を BVE の Scenarios フォルダにコピーします。
  4. BVE を起動し、シナリオ一覧から「東京メトロ日比谷線」を選択してください。
