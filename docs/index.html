インストール方法

  1. BVE Trainsim 5 をインストールしてください。
  2. 上のボタンから路線データのZIPをダウンロードします。
  3. ZIPを解凍し、中身（東京メトロ日比谷線-38S_北千住行.txt・東京メトロ日比谷線-46S_北千住行.txt と Tadimaru フォルダ）を BVE の Scenarios フォルダにコピーします。
  4. 車両を用意します。 本路線の指定車両「東京メトロ13000系」を 車両データのページ から入手してください（v0.3.1 なら Vehicle = 行は設定済みです）。
  5. BVE を起動し、シナリオ一覧から「東京メトロ日比谷線」を選択してください。

運転方法（ATC起動手順）

始発駅出発前に、以下の手順で保安装置を起動してください。

  1. 非常ブレーキをかけ、シフトレバーを中立にします。
  2. 8キーを押して保安装置を「東京メトロ（営団）」に設定します。
    ※ 指定車両の13000系の場合は、右側のモニターに「地下鉄」と表示されます。これが表示されていれば次のステップに進んでください。（車両によって表示は異なる場合があります）
  3. ブレーキを緩めると ATC が作動します。
