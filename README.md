## インストール方法

1. [BVE Trainsim 5](https://bvets.net/) をインストールしてください（無料）。
2. このリポジトリのリリースページからZIPをダウンロードします。
3. ZIPを解凍し、`Scenarios/` フォルダの**中身**を BVEの `Scenarios` フォルダにコピーします。
   ```
   BVE の Scenarios フォルダ/
   ├── 東京メトロ日比谷線-38S_北千住行.txt   ← ここに配置（朝ラッシュ）
   ├── 東京メトロ日比谷線-46S_北千住行.txt   ← ここに配置（昼間）
   └── Tadimaru/
       └── 東京メトロ日比谷線/                ← ここに配置
   ```
4. **車両を指定します**（後述）。
5. BVE を起動し、シナリオ一覧から「東京メトロ日比谷線」を選択してください。

---

## 車両について

本路線の実車 **東京メトロ13000系** を配布しています（2026年6月10日公開）。ATC（メトロ総合プラグイン）対応の自作車両で、これを使えば路線とあわせてすぐに運転できます。

→ 車両データは[リリースページ](https://github.com/tadimaru/bve-hibiya/releases)（`bve-hibiya-13000-vX.Y.Z.zip`）または[配布ページ](https://tadimaru.github.io/bve-hibiya/)からダウンロードしてください。

### 手順

1. 車両データのZIPを解凍し、中身の `Tadimaru` フォルダを BVE の `Scenarios` フォルダにコピーします（路線データと同じ `Tadimaru` に統合されます）。
2. テキストエディタで以下のシナリオファイルを開きます：
   - `東京メトロ日比谷線-38S_北千住行.txt`
   - `東京メトロ日比谷線-46S_北千住行.txt`
3. `Vehicle =` の行を以下に書き換えます：
   ```
   Vehicle = Tadimaru\東京メトロ13000系\Vehicle.txt
   ```
4. 保存して BVE で読み込みます。

> 💡 お手持ちの他の車両（メトロ総合プラグイン対応）を使うこともできます。その場合は `Vehicle =` 行をその車両ファイルへのパスに書き換えてください。
