## インストール方法

1. [BVE Trainsim 5](https://bvets.net/) をインストールしてください（無料）。
2. このリポジトリのリリースページからZIPをダウンロードします。
3. ZIPを解凍し、`Scenarios/` フォルダの**中身**を BVEの `Scenarios` フォルダにコピーします。
   ```
   BVE の Scenarios フォルダ/
   ├── 東京メトロ日比谷線-38S_北千住行.txt   ← ここに配置（朝ラッシュ）
   ├── 東京メトロ日比谷線-46S_北千住行.txt   ← ここに配置（昼間）
   └── Tadimaru/
       └── 東京メトロ日比谷線/                ← ここに配置
   ```
4. **車両を指定します**（後述）。
5. BVE を起動し、シナリオ一覧から「東京メトロ日比谷線」を選択してください。

---

## 車両の指定について

本路線データには **車両は同梱されていません**。お手持ちの車両（メトロ総合プラグイン対応）をご用意のうえ、シナリオファイル内の `Vehicle =` 行を書き換えてください。

### 手順

1. テキストエディタで以下のシナリオファイルを開きます：
   - `東京メトロ日比谷線-38S_北千住行.txt`
   - `東京メトロ日比谷線-46S_北千住行.txt`
2. `Vehicle = ここにお好きな車両を指定してください` の行を、お手持ちの車両ファイルへのパスに書き換えます。
   - 例: `Vehicle = your_vendor\trta13000\Vehicle.txt`
3. 保存して BVE で読み込みます。

> 💡 メトロ総合プラグイン（Ats.dll）対応の車両であれば、ATC 含めて正常に動作します。
